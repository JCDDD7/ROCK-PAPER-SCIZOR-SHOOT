# ROCK-PAPER-SCIZOR-SHOOT
Rock, Paper, Scissors - Python

What I Learned

-  Handle and Sanitize User Input: Using input() to get user data, and chaining string methods like .strip().lower() to handle accidental spaces or mixed-capitalization typing.

-  Control Loop Flow: Using a while True loop to keep the game running indefinitely, and utilizing both continue (to skip invalid inputs and restart the loop) and break (to cleanly exit the game when the user types "no").

-  Write Complex Conditional Logic: Structuring if, elif, and else statements to compare multiple variables and determine the winner based on the game's specific rules.

-  Use the Standard Library: Importing the random module and using random.choice() to allow the computer to pick from a list of options.

-  Format Strings: Using f-strings (e.g., f"Computer chose: {computer_choice.title()}") to dynamically insert variables into print statements and using .title() to make the output look clean.

How to Run
-  Make sure you have Python installed.

-  Clone this repository or download the .py file.

-  Run the script in your terminal:
python your_file_name.py
